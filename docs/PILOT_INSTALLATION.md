# راهنمای نصب و اجرای نسخه آزمایشی حسابداران (Aram Accountant Pilot Installation Guide)

این راهنما مراحل نصب و اجرای نسخه پایلوت و قابل نصب پلتفرم آرام بر روی سیستم‌عامل ویندوژ/دسکتاپ را تشریح می‌کند.

## ۱. پیش‌نیازهای سیستم (Prerequisites)

- سیستم‌عامل: Windows 10 / Windows 11 (64-bit)
- حداقل رم (RAM): 4 GB
- فضای ذخیره‌سازی: 1 GB فضای خالی
- مرورگر اینترنت استاندارد (Google Chrome, Microsoft Edge, Firefox)

## ۲. معماری امنیتی و عدم دسترسی به دیتابیس (Security & DB Credentials Protection)

- **مخفی بودن دیتابیس**: نرم‌افزار دسکتاپ به صورت مستقیم به دیتابیس متصل نمی‌شود. دیتابیس محلی در لایه سرویس پشتی قرار گرفته و هیچ‌گونه رمز عبور یا اتصال دیتابیس در لایه UI قابل مشاهده نیست.
- **ارتباط صرفاً از طریق API**: تمام تعاملات کاربر از طریق فراخوانی استاندارد APIهای REST صورت می‌پذیرد.
- **حفظ حسابرسی و احراز هویت**: تمامی اقدامات کاربر در فایل‌های لاگ حسابرسی (`AuditLog`) به همراه نقش کاربر ثبت می‌گردد.

## ۳. پروفایل‌های انتشار (Deployment Profiles)

نرم‌افزار آرام از سه پروفایل پشتیبانی می‌کند:

1. **`development`**: مخصوص توسعه‌دهندگان با لاگ‌های اشکال‌زدایی.
2. **`pilot`**: مخصوص نسخه آزمایشی حسابداران (دیفالت نسخه دسکتاپ).
3. **`production`**: مخصوص سرورهای عملیاتی با سرویس PostgreSQL.

## ۴. مراحل نصب و اجرا (Installation & Startup Flow)

### روش اول: اجرای مستقیم اسکریپت رانر پایلوت

```cmd
python -m desktop.app_runner
```

### روش دوم: ساخت فایل اجرایی Windows EXE (با PyInstaller)

```cmd
pip install pyinstaller
pyinstaller --onefile --name "Aram_Accountant_Pilot" desktop/app_runner.py
```

پس از اجرای فایل، سرویس محلی بر روی آدرس زیر فعال شده و رابط کاربری فارسی در مرورگر باز می‌شود:
`http://127.0.0.1:8000/`

## ۵. ملاحظات پشتیبان‌گیری و بازیابی داده‌ها (Backup Considerations)

فایل دیتابیس نسخه پایلوت در مسیر زیر به صورت محلی ذخیره می‌شود:
`aram_pilot_hidden.db`

جهت تهیه نسخه پشتیبان، کافیست نرم‌افزار را ببندید و یک کپی از فایل فوق بردارید.
