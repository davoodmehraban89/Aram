# راهنمای انتشار و نصب نسخه آزمایشی دسکتاپ آرام (Aram Accountant Pilot Release Package Guide)

این راهنما تمامی مراحل نصب، راه‌اندازی اولیه، ورود، کاربری حسابداران و پشتیبان‌گیری از نسخه آزمایشی قابل نصب آرام بر روی ویندوز بدون نیاز به پایتون یا ابزارهای برنامه‌نویسی را تشریح می‌کند.

---

## ۱. پیش‌نیازها و فرضیات محیط پاک ویندوز (Clean Windows Environment Assumptions)

- **عدم نیاز به پایتون یا وابستگی‌های توسعه**: فایل بسته اجرایی آرام (`Aram_Accountant_Pilot.exe`) تمامی کتابخانه‌ها، مفسر و موتور پردازش را در درون خود بسته‌بندی کرده است و بدون نیاز به نصب پایتون اجرا می‌شود.
- **سیستم‌عامل**: Windows 10 / Windows 11 (64-bit)
- **فضای ذخیره‌سازی**: حداقل 1 GB فضای خالی

---

## ۲. راهنمای نصب و ساخت فایل اجرایی (Build & Installation Guide)

### ۲.۱. دستور ساخت فایل بسته اجرایی ویندوز (PyInstaller Build Instructions)

جهت ساخت فایل اجرایی تک‌فایلی مستقل:

```cmd
pip install pyinstaller
pyinstaller desktop/aram_pilot.spec
```

فایل خروجی مستقل در مسیر `dist/Aram_Accountant_Pilot.exe` قرار خواهد گرفت.

### ۲.۲. راه‌اندازی اولیه و شورت‌کات دسکتاپ (First-Run & Shortcut)

1. فایل `Aram_Accountant_Pilot.exe` را اجرا کنید.
2. اسکریپت راه‌اندازی اولیه (`first_run_setup.py`) به صورت خودکار:
   - اتصال دیتابیس محلی را اعتبارسنجی می‌کند.
   - جدول‌های دیتابیس را ایجاد می‌کند.
   - کاربر مدیر اولیه (`admin_user`) را ایجاد می‌نماید.
3. میانبر (Shortcut) برنامه را بر روی دسکتاپ قرار دهید تا با یک کلیک اجرا شود.

---

## ۳. راهنمای ورود و کاربری حسابداران (First Login & Accountant User Guide)

### ۳.۱. ورود اولیه به برنامه (First Login)
- **نام کاربری دیفالت**: `admin_user`
- **کلمه عبور دیفالت**: `admin_pass`
- پس از اجرای برنامه، فرم ورود دسکتاپ نمایان می‌شود. با وارد کردن مشخصات بالا وارد حساب ادمین می‌شوید.

### ۳.۲. راهنمای کاربری و گردش کار (User Workflow)
1. **داشبورد اصلی**: اطلاعات شرکت فعال و سال مالی انتخاب‌شده را مشاهده نمایید.
2. **ویزارد بارگذاری**: فایل منبع مالی (CSV/XLSX) را انتخاب نموده و بر روی "شروع پردازش و محاسبه خودکار" کلیک کنید.
3. **مشاهده گزارش‌ها**: گزارش‌های تراز آزمایشی (TB)، ترازنامه (BS) و صورت سود و زیان (IS) را بر اساس آخرین محاسبات مشاهده و دریافت کنید.
4. **بررسی اسنپ‌شات‌ها**: اسنپ‌شات‌های نسخه‌بندی‌شده صورت‌های مالی را بررسی کرده و تایید نهایی را اعمال کنید.
5. **خروجی‌گرفتن**: فایل خروجی CSV یا ساختار PDF را دریافت نمایید.

---

## ۴. مرزهای امنیتی و عدم دسترسی به دیتابیس (Security Boundaries)

- **ارتباط صرفاً از طریق API**: تمام ارتباطات رابط کاربری دسکتاپ با سرویس از طریق پروتکل REST API انجام شده و هیچ‌گونه دسترسی مستقیم به دیتابیس یا اطلاعات اتصال وجود ندارد.
- **حفظ حسابرسی**: تمام عملیات‌های انجام‌شده در لاگ‌های حسابرسی ثبت می‌شود.

---

## ۵. راهنمای پشتیبان‌گیری و بازیابی داده‌ها (Backup & Restore Guide)

- **فایل دیتابیس محلی**: فایل دیتابیس نسخه پایلوت در مسیر زیر قرار دارد:
  `aram_pilot_hidden.db`
- **تهیه پشتیبان (Backup)**: نرم‌افزار را ببندید و یک کپی از فایل `aram_pilot_hidden.db` تهیه نمایید.
- **بازیابی (Restore)**: فایل پشتیبان را جایگزین فایل `aram_pilot_hidden.db` نموده و برنامه را مجدداً اجرا کنید.
