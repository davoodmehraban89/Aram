# مشخصات بسته انتشار نسخه ۱ پایلوت حسابداران آرام (Aram Version 1 Pilot Release Documentation)

**شماره نسخه (Version)**: `1.0.0-pilot`
**تاریخ انتشار (Release Date)**: ۲۳ آگوست ۲۰۲۶
**محیط اجرا (Target Environment)**: Windows 10 / Windows 11 (64-bit)

---

## ۱. ساختار بسته انتشار (Release Package Structure)

```text
Aram_V1_Release_Package/
├── Aram_Accountant_Pilot.exe        # فایل بسته اجرایی مستقل دسکتاپ (PyInstaller Build)

│   ├── PILOT_TESTING_GUIDE.md      # راهنمای چک‌لیست تست پایلوت حسابداران

    ├── sample_trial_balance.csv    # نمونه فایل تراز آزمایشی واقعی
    └── sample_mapping_template.csv # نمونه الگوی نگاشت حساب‌ها
```

---

## ۲. الزامات نصب و راه‌اندازی (Installation Requirements)

- **بدون نیاز به پایتون یا ابزار برنامه‌نویسی**: فایل `Aram_Accountant_Pilot.exe` کاملاً مستقل و خوداتکا است.
- **پردازنده و رم**: حداقل 2-Core CPU و 4 GB RAM.
- **دسترسی شبکه**: تنها نیازمند پورت محلی `127.0.0.1:8000` جهت ارتباط داخلی UI با سرویس.

---

## ۳. محدودیت‌های شناخته‌شده (Known Limitations)

1. **دیتابیس محلی نسخه دسکتاپ**: دیتابیس محلی دیفالت SQLite برای حجم داده‌های تا ۵۰,۰۰۰ سطر مالی بهینه است. برای حجم‌های بالاتر، استفاده از نسخه سروری PostgreSQL (مندرج در `docker-compose.yml`) توصیه می‌شود.
2. **ارتباط تحت شبکه دسکتاپ**: برنامه به صورت تک‌کاربره بر روی سیستم حسابدار اجرا می‌شود؛ همگام‌سازی چندکاربره همزمان نیازمند استقرار نسخه Docker سروری است.

---

## ۴. فرآیند دریافت بازخورد پایلوت (Pilot Feedback Process)

حسابداران می‌توانند بازخوردها، پیشنهادها یا اصلاحات نگاشت حساب‌ها را از طریق بخش بازخورد نرم‌افزار یا ارسال فایل‌های نمونه ذخیره‌شده ثبت فرمایند. سیستم به صورت هوشمند از اصلاحات نگاشت یاد گرفته و آن را در الگوهای بعدی ثبت می‌نماید.
